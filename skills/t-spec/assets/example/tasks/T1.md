# T1 — Add `formatTodosJson` serializer with tests

## Context

A pure function that maps `Todo[]` to the public JSON string. T2 wires it
into the CLI; other commands may reuse it later.

## Constraints and contracts

- Each object has exactly `id` (number), `title` (string), `done` (boolean),
  in that order.
- `createdAt` and any future internal fields are never emitted.
- An empty list serializes to `[]`.
- TypeScript strict mode; no `any`.
- Titles containing quotes or newlines are escaped by `JSON.stringify`.

## Dependencies

None.

## Files

- Create: `src/format/json.ts`
- Test: `src/format/json.test.ts`

## Interfaces

- Consumes: `Todo` from `src/model.ts`
  (`{ id: number; title: string; done: boolean; createdAt: Date }`)
- Produces: `export function formatTodosJson(todos: Todo[]): string`

## Steps

1. Create `src/format/json.ts`:
   ```ts
   import type { Todo } from "../model";

   export function formatTodosJson(todos: Todo[]): string {
     return JSON.stringify(
       todos.map(({ id, title, done }) => ({ id, title, done })),
       null,
       2,
     );
   }
   ```
2. Create `src/format/json.test.ts` with the three tests below, building
   `Todo` fixtures inline with a fixed `createdAt`.

## Tests

- `serializes id, title, done in that order` — parse the output and check
  `Object.keys(result[0])` equals `["id", "title", "done"]` and values
  match; run: `npx vitest run src/format/json.test.ts`
- `omits createdAt` — output string does not contain `createdAt`.
- `returns [] for an empty list` — `formatTodosJson([]) === "[]"`.

## Acceptance

- All three tests pass; the function has no side effects.

## Verification

- `npx vitest run src/format/json.test.ts` → 3 passed.
